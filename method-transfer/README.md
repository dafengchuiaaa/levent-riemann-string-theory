# Levent–Riemann 方法迁移

**已测试的路线。** 以 DGW 猜想 1 的 $(s;s_1,s_2)=(6;4,4)$ 为基准，比较 Alpöge–Claude 发布源码中的 Rallis 核内积引理与 DGW 的分裂格及 DKS 特解。[测试全文](rallis-dgw-6-4-4.md) · [Alpöge 原始说明，第 4 页](https://alpo.ge/remark.pdf#page=4)

直接代入违反正定稳定范围及尖形式输入条件。内积恒等式也没有给出 DKS 特解的有符号小高度迹。权重 12 的补全系数来自已经归档的 FKL–DKS 路线。[权重 12 基线](../weight-12/s-cocycle-proof.md)

本次测试结论限于所选引理与直接代入方式。待有适用于分裂格、非尖输入并能识别 DKS 边界泛函的正则化恒等式，再测试相应迁移。
