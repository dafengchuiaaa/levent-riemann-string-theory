# 撤回记录

记录撤回或订正的范围及依据。

| 条目 | 撤回的内容 | 原因与影响 |
|---|---|---|
| 半整数指标 Bessel 推导 | 将适用于半整数源指标的那条推导直接移用于当前整数源指标，以此证明目标系数 | 两种指标情形采用的特解构造和适用谱不同，直接移用缺少论证。撤回针对这一推导；整数指标问题中的合法 Bessel 展开按各自适用条件判断。 |
| FKL 尖点项正号 | 档案早期沿用了 FKL arXiv v1 式 (37) 的正号 | 重新计算 Petersson 迹项与 Mellin 移线后，式 (36) 的正则化结果中，尖点项取负号。系数比的大小为 540，有符号比为 $-540$。[订正推导](../weight-12/s-cocycle-proof.md) |
