# 撤回记录

撤回依据来自《理论物理低垂果实》的归档交接。早期逐式手稿未随交接取回，以下保留能确认的撤回范围。

| 条目 | 撤回的内容 | 原因与影响 |
|---|---|---|
| 11088 | 早期推导中采用的系数 11088 | 交接明确指出依据不足。原算式及所在位置不详，不能指定一个“替换值”。引用到它的计算需从相应原式复核。权重 12 可引用的各个系数及其含义见计算稿。 |
| 半整数指标 Bessel 推导 | 将适用于半整数源指标的那条推导直接移用于当前整数源指标，以此证明目标系数 | 两种指标情形采用的特解构造和适用谱不同，直接移用缺少论证。撤回针对这一推导；整数指标问题中的合法 Bessel 展开按各自适用条件判断。 |
